# My Favorite Things Website

## Overview

This project is a storytelling-style personal website built using HTML. It shares my journey, interests, goals, and inspirations through structured sections called "chapters." It reflects both my technical learning and personal growth.

---

## What This Project Contains

* A multi-section webpage with chapters:

  * Books that changed my thinking
  * My love for technology
  * Favorite foods
  * Places I want to visit
  * My faith journey
  * My future goals
  * A day in my life
* Lists (ordered and unordered)
* Images to support content
* Structured storytelling format

---

## What I Learned

### HTML Structure

* Using semantic layout elements:

  * `<header>`
  * `<main>`
  * `<section>`

### Content Organization

* Breaking content into logical sections
* Structuring long-form content like a story

### Lists

* Using `<ul>` for technologies and interests
* Using `<ol>` for goals and priorities

### Media Usage

* Adding images to support storytelling
* Understanding how visuals improve user experience

---

## Key Takeaways

* HTML is not just about structure—it can also tell stories
* A well-organized page improves readability and user experience
* Consistency in structure makes code easier to maintain

---

## Challenges Faced

* Organizing long content into clear sections
* Structuring a large HTML file without CSS
* Balancing storytelling with technical structure
